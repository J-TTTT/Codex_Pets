## 已确认的角色设计

- 棕色长卷发、明亮棕色动漫眼睛、圆润脸颊、甜美笑容、淡淡腮红与金色耳饰。
- 白色不对称单肩领口，银白色束腰带竖向结构线，束腰下缘保留铜棕色做旧细节。
- 白色褶皱长裙与长头纱，保留原图主要焦边、孔洞与不规则边缘。孔洞、露出的内层布料与做旧阴影均按原设计处理。
- 金色麦克风带黑色细节，固定由角色的**右手**握持；正面时位于观者左侧。单肩领口保持在角色**左肩**，正面时位于观者右侧。
- 细腻日系二次元线稿、柔和赛璐璐上色与发丝高光，白色布料使用浅灰和淡紫灰阴影，束腰使用手绘高光。

动作保持轻柔。长裙不会变成短裙，头纱连接在原有头部位置；素材没有背景场景、文字、水印、地面阴影或额外婚礼道具。


若使用自定义 `CODEX_HOME`，使用其下的 `pets/gem-bridal/`。已有同名拍档时先备份，再决定是否替换。不要多套一层解压目录，不要修改配置中的图集文件名。文档、预览与检查记录可保留在交付目录，无须复制到安装目录。

## 常见问题

**刷新后没有出现拍档：** 检查两个安装文件是否直接位于正确的 `pets/gem-bridal/` 内，文件名与配置是否对应，然后重新刷新；必要时重启应用。

**只看到静态角色：** 检查系统是否启用了减少动态效果；应用会遵循该设置。静态预览 `avatar.png` 本身不包含动画。

**图片查看器出现棋盘格：** 棋盘格用于显示透明区域。安装时应使用原始 `spritesheet.webp`，不能用截图或 GIF 代替。

**裙摆或头纱上有孔洞：** 带焦边的孔洞和不规则边缘来自已确认的舞台服装设计，属于有意保留的细节。

**备份包中为什么有很多检查文件：** 这是完整交付包，方便以后复查与维护；应用运行只需要配置与 WebP 图集。部分原始检查报告记录制作时的绝对路径，属于历史证据；交付导航和 [运行摘要](qa/run-summary.json) 已整理为包内可用路径。
